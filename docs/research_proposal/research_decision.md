# Research decision

**Decision: REVISE / PROCEED TO A SMALL FALSIFICATION STUDY.** H1 is a worthwhile question; no method is yet verified novel or paper-ready. H2 should constrain claims about what short history can identify.

The scientific opportunity is to learn whether an early individual residual will persist at the requested forecast horizon, using other entities while avoiding an incorrect transfer assumption. The strongest existing explanation is a properly fitted hierarchical random-effect plus mean-reverting state model. The most plausible methodological route is a direct, horizon-specific prospective benefit learner, tested against that model and an equal-capacity generic gate. This is a candidate mechanism, not a novelty verdict.

**What is missing:** full method-level audit of the closest Qin, panel EB, LEAF and Meta-iLaD papers; eligible data audit; evidence of heterogeneous persistence; and a locked comparison showing incremental value beyond EB/Kalman and generic gates. An unrestricted per-individual safety guarantee is not realistic.

**Smallest next experiment:** frozen global forecasts on held-out UCI electricity clients, two early-history lengths and three horizons, comparing residual decay, EB, Kalman, equal-capacity horizon gate and a direct prospective benefit learner. Synthetic persistent/shock controls test interpretation. If the standard state-space model or generic gate matches the candidate, pivot to the H2 limits question or stop. London is the next independent dataset if the pilot passes; glucose is an eventual cross-domain check.
